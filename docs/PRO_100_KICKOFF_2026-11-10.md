## Mission
Develop a faithful native **Windows 10/11 x64** PC port of **Transformers: Dark of the Moon (2011, Xbox 360)** using the user's personally supplied original Xbox 360 ISO as the installation source. The finished distributable should be a code-only native runtime and installer. A user provides their own original ISO when installing, and the installer extracts/copies required data locally. It must not bundle game executable code or copyrighted original assets. Build incremental private test drops that the owner can drag into a local test directory.

This effort is completely separate from Transformers PC Merge and Universal Player System (UPS).
